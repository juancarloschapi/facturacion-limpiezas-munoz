# Facturación Limpiezas Muñoz

Programa de escritorio para Windows de facturación (facturas A, B y extras por trimestres, presupuestos y contratos).

Este repositorio solo se usa para **publicar las actualizaciones** del programa. El programa comprueba aquí si hay una versión nueva (sección *Releases*) y se actualiza solo desde **Ajustes → Actualizaciones** o con el aviso "Actualizar ahora".

- Los datos (facturas, clientes, ajustes) **no** están aquí: se guardan solo en el PC de cada usuario (`Documentos\Facturacion Limpiezas Munoz`).
- Antes de cada actualización el programa guarda una copia de seguridad automática.

## Instalación manual

Descarga el `.exe` de la última versión en [Releases](../../releases/latest) y ejecútalo. Si Windows muestra el aviso azul: **Más información → Ejecutar de todas formas**.
